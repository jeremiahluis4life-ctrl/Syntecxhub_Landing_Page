# Syntecxhub Landing Page

Project 2 of the Syntecxhub Front-End Development internship: a landing page for **Kopa Coffee**, a made-up fresh-roasted coffee subscription in Lagos.

## What's in it

- **Hero section:** headline, short pitch, two call-to-action buttons and a product photo
- **Features:** four feature cards plus a three-step "how it works"
- **Call-to-action:** pricing plans and a closing CTA band
- **Responsive navbar:** sticky header with smooth scrolling to each section, and a full-screen menu on phones
- Extra sections: this month's coffee and an FAQ (native `<details>`, no JS)

## Details

- Layout uses CSS grid and flexbox throughout
- Hover animations on buttons, nav links, cards, icons, photos and FAQ toggles
- Works from 320px phones to wide desktops
- Accessible: skip link, visible focus, the menu button reports open/closed, Esc closes the menu, respects `prefers-reduced-motion`
- About 20 lines of JavaScript, used only for the mobile menu toggle

## Run it

Open `index.html` in a browser.
